# 🗳️ CivicGuide AI
> An AI-powered civic education platform for India — multilingual, gamified, and agentic.

## Tech Stack
- **Frontend**: Next.js 14 + Tailwind CSS + shadcn/ui
- **Backend**: FastAPI (Python)
- **AI**: Anthropic Claude API + LangChain Agents
- **DB**: Supabase (PostgreSQL)
- **Deploy**: Vercel (frontend) + Render (backend)

## Features
- 🤖 AI Election Assistant (multilingual: EN/HI/TE/TA)
- 🎮 XP-based Gamified Learning
- 📊 Dynamic Quiz & Flashcard Engine
- 🗺️ Polling Day Simulation
- 📜 Constitution & Election Law Learning
- 🔔 ECI Notifications & Announcements
